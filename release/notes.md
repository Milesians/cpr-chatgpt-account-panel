## v0.1.0

第一个版本：按账号查看 ChatGPT 官方用量（按使用位置，单独算出 Work 的用量）、订阅与账单、登录设备。

- 列表：CPR 记下的额度、最近一次官方用量、最近支付；Work 有用量的排最前；查询全部用量 / 账单可以中途停
- 详情：7/14/30 天官方用量（额度窗口、每天按位置的堆叠图、位置/发起方式/模型占比、每日 Token）；订阅（含付款逾期的宽限期）与账单分页
- 登录设备：查看设备、登出一台、登出其他设备（保留 CPR 的会话）、登出所有设备（CPR 的令牌随之失效）；会话 ID 不出插件，每次登出前重新核对列表
- 登录与导入：CPR 已有账号可用保存的密码和 2FA 免输重登，或手动走 OAuth；粘贴 `邮箱----密码----2FA` 批量导入新账号，经借道账号的代理登录，由 CPR 管理接口（`oauth/start` + `oauth/complete`）建号并绑定同一个代理，借道账号没绑代理就拒绝导入；导入需要在设置里填 CPR 地址和管理 API Key
- 密码和 2FA 明文存在插件私有状态的 `login` 命名空间，不进日志、错误信息和页面
- 用量、账单、设备列表只发 GET，经账号在 CPR 绑定的代理，不刷新令牌；写入只有登出设备、重新登录写回凭据和导入新账号；令牌不进页面、私有状态或日志
