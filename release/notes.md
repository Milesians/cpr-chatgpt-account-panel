## v0.1.4

- 不用再配 CPR 地址和管理 API Key：插件改经宿主内部调用 CPR 管理接口。旧的这两项设置已不再使用，可以清空，并在 CPR 设置里删掉当时为插件生成的管理 Key
- 导入账号改成直接选代理：下拉框列出 CPR 的代理和各有几个账号在用，插件在后台挑一个绑着它的账号发登录请求，新账号绑在所选代理上。没有账号在用的代理只能浏览器手动登录，停用的代理不能选
- 账号有多个工作区或组织时，直接点选重试（详情页和导入行都可以），不用再手抄 ID
- 2FA：验证码所在的 30 秒窗口只剩 4 秒以内时等下一个窗口再提交；“发起 2FA 验证失败”和“验证码被拒”分开报，不会把网络问题当成密钥填错
- Linux 安装包（x86_64 和 aarch64）都锁到 glibc 2.28，在 CPR 官方 Debian 12 镜像和更老的系统上都能启动

## v0.1.3

- 「查询全部用量」「查询全部账单」和勾选后的批量查询改成同时查 6 个账号（各走自己绑定的代理），停止后不再发起新的；批量免输重登仍然一个接一个
- 列表的每日 Token 柱状图：悬停或点按柱子弹出当天详情（日期和星期、Token 原值、占这段时间的比例、是否是这几天最高）

## v0.1.2

列表页的官方用量改成图：

- 每行显示近 7 天（或上次查询的天数）每日 Token 的柱状图和合计，悬停柱子看当天的 Token
- 使用位置占比画成饼图，悬停看各位置的占比；常见位置颜色固定，和详情页一致
- 列表不再对 Work 做特殊处理：去掉「Work 有用量」筛选、「按 Work 占比排序」、紫色竖条和顶部的 Work 计数；新增「按 Token 用量排序」
- 详情页不变
- 旧版本查过的账号没有记下每日 Token，重新「查询全部用量」后显示

## v0.1.1

界面整理：措辞、布局和按钮按审查清单统一了一遍。

- 账号列表：令牌过期的账号行内直接「免输重登」（没存密码的显示「去重新登录」）；勾选多个可以「批量免输重登」，可中途停止；窄屏下「详情」按钮不再被裁掉
- 「登录与导入」改名「导入账号」，只管导入：粘贴后自动预览，只有一个「导入 N 个」按钮；已有账号的重登移到账号列表和详情页
- 详情页不再分 tab，从上到下是用量、订阅与账单、重新登录、登录设备；头部只放身份信息，Work 占比和支付状态不再重复出现
- 「查询订阅」「查询账单」合成一个按钮；查过后各区按钮统一叫「刷新」
- 只有「登出所有设备」需要确认，登出单台和登出其他设备直接执行
- 颜色：红是扣款失败和查询报错，黄是令牌过期、待续费和周额度超过 90%，紫只给 Work
- 套餐名显示成 Plus / Pro / Team，Team 套餐不再重复显示类型；英文状态值和错误码不再出现在界面上，登录错误码前后端对齐
- 发票只留「复制发票链接」按钮
